# minor_project
This repository contains the implementation of an AI-powered resume analyzer and screening system designed to enhance recruitment efficiency, fairness, and scalability using Google's Gemini generative AI model and a Streamlit-based web application.Key Features
AI Resume Parsing & Matching: Evaluates candidate resumes against job descriptions using prompt engineering and instruction-based reasoning without requiring custom dataset training.
Structured JSON Outputs: Generates a job-description (JD) matching score, identifies matching and missing keywords, assesses strengths and weaknesses, and provides actionable resume improvement suggestions.
Explainable AI (XAI): Enhances recruiter trust by providing clear, interpretable logic behind each score based on technical skills, project relevance, formatting, and domain expertise.
Hybrid AI-Human Model: Automates high-volume technical screening while preserving human oversight for evaluating soft skills, cultural fit, and interpersonal attributes.
